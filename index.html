Privacy

Daily tallies. Each day, Timr adds one to a tally in Classhelpr's database at Supabase, in Canada (Montreal), the first time a browser opens it. It does the same the first time that browser starts a timer or the stopwatch, shows the clock, turns on the voice meter or voice bar, picks a theme, goes full screen or pops the timer out, and when a countdown reaches zero. A tally is a date, the action and a number. It holds no name, no device details and nothing about who. No cookie is set for it. Your browser remembers the date it was last counted, so Timr counts each browser once per day, week and month. That date never leaves your browser.

The microphone's sound never leaves your computer. Timr listens in memory and never records, stores or sends it.

Do Not Track and Global Privacy Control stop the tallies, and so does opening timr.classhelpr.com/?nocount=1.
